any week where something happened. Record what is NOT obvious from the code: decisions and why,
things tried and abandoned, parameter choices, open questions, what's next.

Keep participant-level detail (sample IDs, identifiers) OUT of this file — point to a gitignored
table in results/ instead. This file stays in the private repo and is excluded from publication.
